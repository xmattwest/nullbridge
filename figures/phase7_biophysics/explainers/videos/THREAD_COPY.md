## Reply 2 (`reply2_cortical_core.mp4`)

Running synaptic knockouts across the loop core reveals the same circuit motif neuroscientists see in cortex, where coincidence-detecting fibers team up with parallel backup tracts inside a ring of inhibition.

Any circuit that reuses the same weights in a loop has to damp random directions so noise can't compound, amplify only when a search signal and a matching key arrive together, and run redundant lines so partial steps survive the next pass.

## Reply 3 (`reply3_coda_prism.mp4`)

Just like premotor cortex rehearses a movement in a rotated neural subspace so your muscles don't twitch while you're still deciding, Inkling's loop computes in an internal shorthand that looks like gibberish over 93% of the time to standard word probes.

Thinking directly in word coordinates would tug every half-finished step toward a premature guess, so keeping the loop rotated away from language and refracting it through a six-layer exit lens lets the model finish the thought before committing to a word.
